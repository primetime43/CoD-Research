# XAnim Asset

Animation data for models.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](../AssetTypes.md) for the full list.

## Overview

XAnim assets store skeletal animation data used for:
- Character movement
- Weapon animations
- Vehicle animations
- Environmental animations

## Key Components

- Bone transformations over time
- Animation events/notetrack
- Blending data
- Loop settings
