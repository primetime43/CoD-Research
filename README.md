# CoD Research

Welcome to the CoD Research Repository! This repository contains research and documentation for Call of Duty titles from CoD4 to CoD10.

> **Community Resource:** The purpose of this wiki is to preserve knowledge collected by the community over the years from various forum threads and posts—much of which has become difficult to access or lost as forums have been shut down.

## Cloning

All games now live in this single repository, one folder per title:

```bash
git clone https://github.com/primetime43/CoD-Research.git
```

Each game's documentation is in its own folder named `Game Name - COD#` (e.g.
`Modern Warfare - COD4`, `World at War - COD5`, `Ghosts - COD10`).
