# Sound Asset

Sound definitions with volume, pitch, distance, and speaker mapping.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](FastFiles/AssetTypes.md) for the full list.

## Overview

Sound assets define how audio is played in-game, referencing loaded sound data with playback parameters.

## Key Properties

- Volume and pitch
- Distance attenuation
- Looping behavior
- Channel/speaker mapping
- Randomization ranges
