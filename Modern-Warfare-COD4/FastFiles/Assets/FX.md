# FX / Visual Effects Asset

Visual effects system for particles, sprites, lights, and models.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](FastFiles/AssetTypes.md) for the full list.

## Overview

FX assets define visual effects like explosions, smoke, fire, sparks, and environmental effects.

## Key Components

- Particle emitters
- Sprite rendering
- Dynamic lights
- Trail effects
- Sound triggers
