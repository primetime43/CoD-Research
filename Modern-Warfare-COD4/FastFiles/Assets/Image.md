# Image Asset

Texture images for materials and UI.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](FastFiles/AssetTypes.md) for the full list.

## Overview

Image assets store texture data used by materials for rendering surfaces.

## Image Types

- Color maps (diffuse textures)
- Normal maps
- Specular maps
- Detail maps
- UI textures

## Platform Differences

- **PS3/Xbox 360**: Platform-specific texture compression
- **PC**: DXT compression formats
