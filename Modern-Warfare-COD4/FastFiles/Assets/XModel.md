# XModel Asset

3D model data including geometry, materials, and LODs.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](FastFiles/AssetTypes.md) for the full list.

## Overview

XModels are the primary 3D model format used for:
- Player models
- Weapons
- World objects
- Vehicles
- Props

## Key Components

- **LODs**: Multiple detail levels for distance-based rendering
- **Materials**: Surface appearance definitions
- **Collision**: Physics collision geometry
- **Bones**: Skeletal structure for animation
