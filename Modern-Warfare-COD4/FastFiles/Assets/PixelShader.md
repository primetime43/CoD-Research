# Pixel Shader Asset

Pixel shader programs for rendering.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](../AssetTypes.md) for the full list.

## Overview

Pixel shaders (fragment shaders) compute the final color of each pixel during rendering.

## Platform Notes

- Present on PS3 and Xbox 360
- NOT present on PC (shaders compiled differently)
