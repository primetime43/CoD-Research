# Loaded Sound Asset

Raw sound data loaded into memory.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](../AssetTypes.md) for the full list.

## Overview

Loaded sound assets contain the actual audio waveform data that sound assets reference.

## Format

Audio data stored in platform-specific formats.
