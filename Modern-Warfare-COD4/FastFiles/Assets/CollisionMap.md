# Collision Map Asset

Collision geometry for maps.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](FastFiles/AssetTypes.md) for the full list.

## Overview

Collision map assets define the physical collision surfaces used for:
- Player movement
- Bullet traces
- Grenade bouncing
- Physics interactions

## Types

- `col_map_sp` - Single player collision map
- `col_map_mp` - Multiplayer collision map
