# Graphics Map Asset

Rendering data for maps including visibility, lighting, and draw surfaces.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](../AssetTypes.md) for the full list.

## Overview

Graphics map assets contain all visual rendering data for a map:
- Draw surfaces
- Visibility data (PVS)
- Static lighting
- Reflection probes
- Light grid data
