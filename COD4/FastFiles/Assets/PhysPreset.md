# Physics Preset Asset

Physics behavior presets for dynamic objects.

> **Note:** Asset type IDs vary by platform. See [AssetTypes.md](../AssetTypes.md) for the full list.

## Overview

Physics preset assets define how objects behave physically:
- Mass
- Friction
- Bounciness
- Buoyancy
