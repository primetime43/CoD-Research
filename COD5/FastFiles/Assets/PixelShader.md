# Pixel Shader Asset

Pixel shader programs for rendering.

## Overview

Pixel shaders (also called fragment shaders) are GPU programs that determine the final color of each pixel during rendering.

## Purpose

- Calculate final pixel colors
- Apply textures and lighting
- Implement visual effects (bloom, fog, etc.)
- Handle transparency and blending
