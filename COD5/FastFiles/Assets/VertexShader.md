# Vertex Shader Asset

Vertex shader programs for rendering.

## Overview

Vertex shaders are GPU programs that transform vertex positions and prepare data for the pixel shader stage.

## Purpose

- Transform vertices from model to screen space
- Calculate per-vertex lighting
- Pass data to pixel shaders (normals, UV coordinates)
- Implement vertex-based effects (skeletal animation, wind)
